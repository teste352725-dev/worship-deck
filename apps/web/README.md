# Worship Deck Web

Esta aplicação usa **o mesmo frontend** de `apps/deck/public`.

Antes de publicar no Vercel, execute `npm run build` nesta pasta. O script copia a interface compartilhada para `public/`.

A API Web deve implementar o contrato descrito em `docs/RUNTIME-CONTRACT.md`. O frontend não deve conter forks específicos para Local ou Web.
